# Contributing

The Wolf Community source is **source available**, not OSI open source.
Do not describe it as open source in PRs, docs, or comments.

Inbound contributions need a counsel-approved contributor agreement before
they can be accepted. Until that lands, please open an issue rather than a
material pull request.

`main` requires a pull request and the GitHub Actions check named `test`.
Admins cannot bypass that check; do not push commits straight to `main`.

Do not copy files from `wolf-enterprise` into this repository.
Do not invent Business Source License grant text; counsel owns `LICENSE`.
