# Autofix master gate — F01 complete

Date: 2026-10-24. Implementation and focused acceptance complete; no deployment performed.

The API and orchestrator share the default-off setting check. Workers leave disabled jobs queued, return jobs claimed before disable to the queue, and cancel running work on the next heartbeat (normally 10 seconds). Setting read errors fail closed. Engine-turn and pre-publication checks provide additional boundaries. Administrative setup consoles remain available.

The UI uses the shared flag hook and fails closed on refresh errors. Disabled scan/finding surfaces show a role-aware setup notice. Existing job details and cleanup remain accessible while continuation is disabled. The disabled engine endpoint exposes only a configured boolean; its TypeScript response now reflects the optional enabled-only fields. The Agents page reuses the shared setup notice instead of inviting ordinary users to enable an admin setting.
