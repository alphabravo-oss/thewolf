# F07.6 — actual branch edit discovery

Workspace metadata now pins a verification base before an agent runs. Verification enumerates the diff from that commit to the working tree plus untracked files, so staged edits and agent-created commits remain visible after restart. Ordinary dirty-file checks used by cleanup retain their HEAD-relative behavior. Existing branches and legacy metadata adopt and persist a resolvable default-branch fork point; missing/unresolvable bases fail with the workspace retained. Base object IDs are validated before use as Git arguments.

The orchestrator replaces the agent's file list with these Git results before formatting and deciding which findings require verification. A skip claim cannot suppress a finding in an actually edited file. Invented file claims without real edits do not reach verification. Findings review documents are regenerated for each invocation and removed before edit discovery, preventing Wolf's own prompt from counting as an agent edit; a review-write failure stops the run.

`go test -race ./internal/fix/... -count=1` passes ([receipt](fix-actual-edits.txt)). Real Git tests cover committed, staged and untracked files (including whitespace), reopen after a default-branch ref move, legacy fork-point adoption, cancelled enumeration and invalid baseline metadata. Orchestrator checks cover omitted/invented file claims, agent commits, modified-but-skipped findings, and empty runs. Partial-turn fixtures now model actual workspace changes; the shared-file test proves that omitting file claims cannot delay rejection to a later turn. Scoped lint ([receipt](fix-actual-edits-lint.txt)) and `make scanners-sync` ([receipt](fix-actual-edits-sync.txt)) pass.

This qualifies discovery and delivery of actual edits to the existing verifier. It does not complete final branch acceptance: extra files outside targeted findings, regression checks across tools/committed rounds, rejected agent-created commits, and the full cancellation/restart attempt-history matrix remain F07.6 work. No deployment or remote publication occurred.
